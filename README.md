# LENSEC Training Program

This repository is used for training activities, assignments, project submissions, and learning resources.

## Repository Rules

1. Create a branch for each feature/task.
2. Open a Pull Request before merging to main.
3. Keep commits descriptive.
4. Place assignment submissions under your personal folder.
5. Do not commit large datasets or credentials.
